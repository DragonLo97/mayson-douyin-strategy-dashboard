可以复制的不是“赞助赛事”四个字

  1. 先固定一个高频时刻运动结束30分钟内，需要方便补充蛋白。
  2. 再固定一个可传播理由开盖即饮，比冲粉更适合通勤、训练场和比赛。
  3. 最后放大同一理由所有达人、直播和商品卡都围绕同一购买理由，不各说各话。

抖音不是一个渠道，而是四个岗位

短视频测试购买理由，达人直播拿新客，品牌自播承接解释和复购，商品卡收搜索与回访。四条链路用同一利润表管理。

核心岗位

拿新客、借信任、快速放量

让已经拥有健身、跑步、营养信任的达人，用独立链接验证“谁能卖、什么话术能卖”。首轮不追求大场，先用垂直小场找到稳定净订单。

必须做

  • 每个达人独立商品链接，隔离价格、内容和退货数据
  • 先纯佣或低固定费，首轮只给可回收的样品成本
  • 按退款后净订单复盘，不按曝光和支付峰值庆功

放量闸门

连续两场单箱贡献为正，且退款率、违规风险均在约定线内，才升级佣金或投流。

达人不按粉丝数签，按净订单能力签

粉丝数只做参考。真正进入合同的，是近30天相关品类净订单、退款率、人群匹配、内容复用权和单箱利润上限。

数据口径

  • 确定事实：用户提供的内部进货条件、公开官网和一手采访。
  • 行业样本：用于确定资源顺序，不冒充迈胜后台。
  • 内部建议参数：达人佣金、退款、人工、投流等均可编辑，用来反推经营边界。
  • 普通款成本：68.67元是卖2补1兑现后的核算货品成本；补货未兑现前，现金仍按103元/箱管理。
  • 运费：88元和103元已含品牌到经销商的进货运费；发往消费者的仓配、包材和快递仍在模型中单独计入。

达人合同红线

  1. 必须按退款后净订单和净GMV结算复盘，不以支付峰值替代。
  2. 每个达人使用独立链接或独立SKU，禁止多达人混用导致归因失真。
  3. 固定费、佣金、平台费、投流全部进入同一场次P&L。
  4. 首轮固定费不得超过“保守净订单 × 佣金后单箱贡献 × 30%”。
  5. 约定价格、口味、赠品、素材授权、违规赔付、退货异常和结算周期。
  6. 头部专项的品牌曝光预算必须与销售利润预算分账审批。
